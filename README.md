# Blog PHP

Simple blog application built with pure PHP following MVC pattern.

## Features
- User registration and authentication
- Create, edit, delete posts
- Comments system
- Access control

## Requirements
- Docker
- Docker Compose

## Installation
1. Clone the repository
2. Copy `.env.example` to `.env` and fill in the values
3. Run `docker compose up -d`
4. Open `http://localhost:8080`

## Tech Stack
- PHP 8.2
- MySQL 8.0
- Nginx
- Docker
